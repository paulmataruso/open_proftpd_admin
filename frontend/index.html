    About Trusted FTP Users

    Each trusted user is chrooted to their own folder under FTP_BASE_PATH/<home_folder> with full read/write access. They cannot navigate above that folder.

    Create the folder on the FTP server before the user first connects. Regular FTP users and anonymous users are unaffected.

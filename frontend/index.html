    About Trusted FTP Users

    Each trusted user is chrooted to their own folder under FTP_BASE_PATH/<home_folder> with full read/write access. They cannot navigate above that folder.

    Create the folder on the FTP server before the user first connects. Regular FTP users and anonymous users are unaffected.

    About Private FTP Users

    Each private user is chrooted to their own folder under PRIVATE_FTP_BASE_PATH/<home_folder> with full read/write access. This is a separate tree from the public FTP root and from Trusted users — private files are not visible to anyone else over FTP or HTTP, and never appear on the public dashboard.

    The home folder is created automatically (mode 750) when the user is added. Deleting a user removes the login only — their folder and files stay on disk.

    ProFTPd reloads automatically when users are added or removed (via the host's ciosuseradd-proftpd-reload unit) — no manual step needed.
